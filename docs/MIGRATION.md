## قواعد الهجرة

1. أي هجرة تحذف أو تستبدل ملفًا قانونيًا تحتاج ADR + أرشيف byte-exact للنسخة السابقة.

4. كل هجرة تُسجَّل هنا **بعد** إثباتها في شجرة GitHub، لا قبلها.
