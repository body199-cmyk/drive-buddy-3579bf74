# M48-T01 — أقسام تنقّل مستقلة للوحة الويب الحديثة

## الطلب والنطاق

تحويل لوحة TeleDrive الحديثة من صفحة طويلة إلى وجهات أقسام منفصلة، مع الاستفادة من فكرة التنقل في نموذج المستخدم المرفق دون نقل بياناته أو منطق المحاكاة. تُحفظ واجهة عربية RTL متجاوبة، كل إجراءات اللوحة الحالية، الثيمات الثلاثة، ومسار تسجيل Telegram الآمن عبر Gradio.

## التنفيذ

- `python-package/teledrive/web_dashboard.py` هو مصدر التنفيذ. أصبحت الصفحة تسع لوحات منفصلة: النظرة العامة، الحسابات، مجلد الحفظ، تحليل الرابط، النتائج، الطابور والنقل، الإعدادات، السجلات، والصيانة/التصدير. تُعرض لوحة واحدة فقط في كل مرة؛ بقية اللوحات تحمل `hidden` وتُبدّل عبر `activateSection`.
- على الكمبيوتر، قائمة جانبية ثابتة وواضحة. على الهاتف/الشاشة الضيقة، شريط تنقل سفلي بخمس وجهات رئيسية، وقائمة «المزيد» للحسابات والإعدادات والسجلات والصيانة. للقائمة إغلاق بالخلفية أو زر الإغلاق أو `Escape`، وتقييد لتركيز لوحة المفاتيح مع إعادته إلى موضعه.
- تحديث hash الصفحة وسجل المتصفح عند اختيار قسم، ودعم الرجوع/التقدم. أزرار مسار الخطوات الخمس في النظرة العامة أصبحت أزرار تنقل حقيقية؛ لا تعتمد على تمرير عنصر مخفي أو على تمرير الصفحة الطويلة.
- تبقى المقاييس والحالة في النظرة العامة حيّة، وتُعرض أعداد النتائج والطابور وشارة اتصال الحسابات من بيانات التشغيل الفعلية فقط. تُحدّث الرسائل والتنقل بعد التحليل والإضافة للطابور كي يرى المستخدم الحالة في الصفحة التالية.
- لم تتغير أفعال الجسر أو خدمات Drive/Telegram/التحليل/الطابور/السجلات/الصيانة. بقيت أدوات النتائج والفلاتر والتحديد الجماعي/النطاق/المجموعة والتحكم الفردي بالطابور. لم يُضف من ملف HTML المرفق أي بيانات أو سلوك تجريبي.
- المصادقة كما هي: لا تُرسل أسرار Telegram أو OTP أو 2FA عبر جسر الويب؛ تسجيل الدخول ما زال في حقول Gradio الآمنة. ألوان فاتح وX `dim` وداكن كامل وإعداد حفظها بعد إعادة التحميل كما هي.
