# M47-T02 — لوحة الويب الحديثة: ثلاث سمات، تحليل قناة يعمل، وسير عمل واضح

## طلب المالك

- إضافة لون واجهة ثالث داكن بدرجة معتدلة بأسلوب X/Twitter «Dim»، مع بقاء الفاتح والداكن الكامل.
- إصلاح تحليل رابط قناة Telegram في لوحة الويب الحديثة.
- إعادة تنظيم الصفحة في خطوات مريحة وواضحة.
- عرض نتائج التحليل داخل صندوق مستقل يظهر نحو عشرة صفوف ويمرّر داخليًا، بينما تستمر بقية الصفحة في التمرير الطبيعي.
- عدم فقد أي وظيفة موجودة، ثم الدمج بعد التحقق.

## سبب فشل تحليل القناة

أعاد اختبار HTTP الحقيقي إنتاج المشكلة قبل الإصلاح:

| الطلب | النتيجة |
|---|---|
| رابط قناة `https://t.me/testchat` مع الوضع الافتراضي القديم `message` | خطأ، بلا نتائج |
| الرابط نفسه مع `chat` | نتائج صحيحة |
| الرابط نفسه مع `latest` | نتائج صحيحة |
| رابط رسالة عام/خاص مع `message` | نتيجة صحيحة |

إذن محرك Scanner كان يعمل؛ الواجهة كانت تبدأ بوضع «رسالة واحدة» حتى عندما يلصق المستخدم رابط قناة بلا رقم رسالة.

## الإصلاح والتصميم

### التحليل التلقائي

- الوضع الافتراضي الآن «تلقائي — يتعرف على الرابط».
- يميز المتصفح رابط الرسالة/الموضوع المباشر فيرسل الوضع القانوني `message`، ويميز رابط القناة/المجموعة/الدعوة/المحفوظة فيرسل `chat` مع حد الرسائل الحالي.
- تبقى الأوضاع اليدوية القانونية الأربعة `message/range/latest/chat` وحقولها وتحققها كما هي؛ لم تتغير دلالة `auto` القديمة في الخادم.
- تلميح حي يشرح ما تم التعرف عليه قبل الضغط، وEnter داخل حقل الرابط يبدأ التحليل، وتظهر حالة انتظار ثم عدد وحجم النتائج، وتنتقل الصفحة لصندوق النتائج عند النجاح.
- عند اختيار «رسالة محددة» يدويًا مع رابط قناة بلا رقم، تمنع الواجهة الطلب الخاطئ برسالة عربية تشرح البديل بدل خطأ غامض.
- وسّع محلل الروابط في الخادم الصيغ المنسوخة الشائعة دون فتح الباب لنطاقات مشابهة: غياب البروتوكول، `www.t.me`، `telegram.me`، روابط المعاينة `/s/`، الاستعلامات والشظايا مثل `?single`، صيغة `@username`، ورابط قناة خاصة `/c/<id>` بلا رقم رسالة.

### خمس خطوات واضحة

1. الاتصال بـTelegram وGoogle Drive.
2. اختيار مجلد Drive.
3. تحليل الرابط.
4. مراجعة النتائج وتحديد الملفات وإضافتها للطابور.
5. بدء النقل ومتابعة الطابور.

أضيف شريط خطوات ثابت المعنى، وشارة حالة لكل قسم، وسطر «الخطوة التالية» يتغير من الحالة الحية. بقيت الإعدادات والسجلات والصيانة بعد الخطوات اليومية بروابط سريعة منفصلة.

### صندوقا النتائج والطابور

- صندوق النتائج بارتفاع `430px` وبحد `62vh`، مع رأس جدول ثابت وتمرير داخلي و`overscroll-behavior: contain`؛ يعرض حتى 1000 صف مطابق بدل 300.
- صندوق الطابور بارتفاع `350px` وبحد `54vh` ويعرض حتى 500 عنصر بدل 80.
- لا يعاد رسم أي صندوق إلا عند تغير بصمته، وتُستعاد مواضع التمرير حتى لا يقفز العرض أثناء التحديث الدوري أو النقل.
- أضيفت أعمدة رقم الرسالة والمجموعة من لقطة الحالة الحية (`messageId`/`groupId`) دون كشف أي سر أو تغيير المستهلكين القدامى.

### ثلاث سمات

- `light`: اللون الفاتح الحالي.
- `dim`: خلفية X الزرقاء الرمادية `#15202B` وبطاقات `#1B2836` وحدود `#38444D` وأزرق X ‏`#1D9BF0`.
- `dark`: الداكن الكامل السابق.

توجد السمات الثلاث في مبدّل أعلى الصفحة وفي الإعدادات، وتُحفظ من خدمة التفضيلات نفسها. أضيفت قيمة `dim` لقائمة تفضيلات الخادم ولوحة ألوان/خيار الواجهة الكلاسيكية حتى لا تصبح القيمة المحفوظة غير صالحة عند التنقل بين الواجهات. تبقى حماية غلاف Gradio الفاتح المتعمدة كما هي لأسباب استقرار Colab الموثقة سابقًا.

## الحفاظ على الوظائف وإكمال الفجوات

- أبقت إعادة التنظيم كل معرفات وأزرار وحقول M47-T01، ويتحقق اختبار DOM من عدم وجود معرف مكرر ومن أن كل مرجع JavaScript يقابل عنصرًا موجودًا.
- جميع الأزرار الـ36 ذات المعرفات مربوطة بمستمع، والأزرار الديناميكية للمجلدات والطابور مربوطة بالتفويض/الرسم نفسه.
- وُصلت وظائف آمنة كانت موجودة في الخادم والجسر لكن غائبة من الصفحة: تذكّر/مسح الرابط، فلاتر النتائج، تحديد نطاق/مجموعة، تحديث الطابور، مسح المكتمل/غير المكتمل، والتحكم الفردي إيقاف/استئناف/إنهاء/إعادة لكل عنصر.
- بقيت بيانات Telegram السرية ورموز الدخول خارج HTTP الحديث وفي حقول Gradio الآمنة كما كانت، وبقيت الواجهة الكلاسيكية احتياطية.
- لم يتغير QueueManager أو TransferManager أو FastTelethon أو حلقة التطبيق الواحدة أو عزل خادم الويب في خيطه.

لا يوجد متصفح Chromium/Playwright داخل بيئة العمل، لذا لم تُلتقط لقطة بصرية آلية. كما لا يثبت أي اختبار محلي جلسة Colab أو Telegram أو Drive حقيقية. يلزم تأكيد المالك بعد نشر الحزمة وتشغيل Notebook من `main`: لصق رابط قناة في الوضع التلقائي، رؤية النتائج داخل الصندوق، تجربة السمات الثلاث، ثم نقل ملف صغير حتى يظهر في مجلد Drive.
